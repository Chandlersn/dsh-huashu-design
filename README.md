# 花叔设计 · DSH 工作台

把 [alchaincyf/huashu-design](https://github.com/alchaincyf/huashu-design) 的设计方法、参考手册、脚本与 92 种风格样张接入 DeepSeek Harness，并在同一面板内接通本机批印坊引擎，形成「创作 → 编辑 → 回存 → 批量出片」一条流程。

这是独立适配插件，不是花叔发布的官方插件。页面使用 DSH 侧栏与主面板插槽，跟随宿主主题和中英文设置。

## 先读：装完你会看到什么

这个仓库**不包含**上游样张与批印坊源码。刚装好能打开面板，但有两块是空的，按需补齐：

| 依赖 | 不补会怎样 | 怎么补 |
| --- | --- | --- |
| 上游快照 `upstream/` | 风格库 0 条、手册与设计说明读不到；`huashu_design` 的 catalog 会返回 `warnings` 提示缺什么 | 见下文「先取上游快照」，一条 `git clone` + `checkout` |
| 批印坊源码树 | 面板能进，五个业务页无引擎可用，请求报「未找到批印坊源程序」 | 装好你自己的 PrintPress，并让插件配置的路径指向它 |

也就是说：**创作、媒介选择、作品库、配色、评审这些开箱可用；92 张风格样张与批印坊批量出片要各自补料。** 缺料时插件会明确报缺，不会假装有内容。

## 使用

安装启用后，侧栏打开「花叔设计」。

### 创作

在「这次，想做什么？」中选择工作区、填写需求，点击「发送并开始创作」，通过原生 Session 提交并把接受后的会话打开。也可先「预览指令」，编辑后发送；预览本身不发送消息。

切换创作类型时，主展示图、媒介标识与参考列表同步更新。网页、幻灯片、信息图、App、小红书展示本类上游样张；动画展示分镜与舞台视觉参考，评审展示版式与信息层级参考。切换类型保留滚动位置与需求文字，不匹配的风格参考会被清除。

「输出格式」对所有媒介可见，默认「常规输出」；显式选择「图片 + 图层工程」才产出原生 `.ppdesign`。分层交付要求真实的 text / rect / ellipse / line / image 独立图层，整张渲染图伪装成单层工程会被拒绝。

界面布局提供「作品画廊」与「目录工作台」两种版式，共用需求、风格、草稿与业务动作，切换时保留输入。

### 风格样张

92 种真实上游样张，可按类别筛选、搜索关键词、看大图并直接选用。每张卡片有独立「设计说明」入口，按需读取本条内容，展示适用场景、视觉特征、字体搭配、参考来源、实现限制与示例色板；标签显示风格气质与上游 HTML 还原度估计。

### 我的作品

登记本机成品及可选源文件，登记不上传也不复制文件。

- **HTML 作品**在卡片上直接显示缩放页面，点击进入全屏；双击正文文字即可修改，顶栏保存或 `Ctrl/Cmd+S` 沿用原作品的版本校验与备份。编辑只更新对应文本，不把预览内联的图片、控制脚本或临时节点写回原文件；动态脚本生成、无法可靠映射的文字会拒绝误写并保留草稿。
- **类型筛选**由已登记作品的实际媒介自动汇总，只列出库里真正存在的类型并带数量，不写死列表。
- **删除**经二次确认后一并删除登记、成品文件、关联源码与原生工程文件；仍被其他作品引用的文件会保留并在结果中列出，符号链接目标永不删除。只想撤销登记时使用「移出作品库」，文件保留。
- **继续修改**在包含源工程的工作区发起对话续改，保留既定方向与原文件。
- **图片与图层工程**进入批印坊编辑：平面图走裁剪、擦除与修复；`.ppdesign` 打开原生图层，文字、形状、图片可单独调整。编辑页上方显示当前关联作品，「保存回作品库」导出新版本 PNG 与 `.ppdesign` 并更新同一条登记，原交付文件与旧工程保留。

### 设计手册

独立阅读视图：正文按标题、列表、引用、表格与代码块排版，桌面左侧提供可筛选章节目录与当前位置，窄面板改为折叠目录。可切换原文、复制全文、返回上一份手册或回到工作台。长文按原顺序拼接，单次最多加载 128000 字符，超出后显示「继续阅读」。代码块可单独复制。

### 批印坊

选择顶部「批印坊」进入五个业务页：名单数据、变量照片、底图制作、模板排版、打印中心，复用本机批印坊的实际引擎与原有数据。页面作为面板中的 Vue 子树挂载，控件映射宿主主题，快捷键与 DOM 查询限制在模块内；切换到其他标签保留编辑状态。

- Excel/CSV 用本机文件选择器，也支持拖拽上传；照片目录、字体、PSD/工程包与输出位置沿用原生对话框。
- PDF、图片导出与系统打印由不显示主窗口的 Electron 业务进程执行，进度实时回传，取消请求可在长任务运行中到达。
- 不需要另开独立的批印坊窗口或开发服务器。首次进入启动后台；插件卸载时等待业务收尾并释放数据目录锁。目录被独立桌面版占用时明确提示。
- 图像处理采用「宿主优先、快速模型兜底」。当前 DSH 未注册抠图提供方时使用已有 MODNet 快速模型，并显示实际来源；已注册宿主服务报错时明确显示，不静默更换来源。宿主与本地快速模型的派生缓存分开，原名单、原图、工程与预设不清除。

这是本机集成：运行依赖原批印坊目录中的 Electron、原生依赖与模型，不把其二进制复制进资源包。目录移动后设置 `HUASHU_PRINTPRESS_ROOT` 并重新构建；Host 可用 `printpressRoot` 指定运行根、`printpressDataDir` / `printpressUserData` 分别指定业务数据与运行缓存。面板内不提供桌面程序的更新、迁移或重启。

### 配色

「配色」提供海蓝、翡翠、紫藤、玫瑰、琥珀、珊瑚六套预设，也可跟随宿主或自选颜色。默认海蓝，选择保存在当前浏览器；背景微染、导航、按钮与内嵌编辑区一起变化，沿用 DSH 明暗底色。切换不重新挂载编辑器，不改变作品画布与导出颜色。

## 工具

### huashu_design

| action | 作用 |
| --- | --- |
| `catalog` | 分页发现任务、风格、流程与资源根目录 |
| `read` | 按路径读取手册/图片，或按 style ID 读取该素材专属设计说明 |
| `draft` | 生成尚未发送的创作草稿，可指定 `outputMode: layered` |
| `edit` | 为已登记作品生成保留原文件与方向的修改指令 |
| `source` | 读取已登记源文件及 revision，或带 content/revision 保存并备份 |
| `list` | 分页读取作品库，可按媒介与风格过滤 |
| `add` | 登记或更新已有交付文件 |
| `remove` | 移除登记记录，保留原文件 |
| `delete` | 删除登记及其成品、源码与原生工程，必须 `confirm: true` |

界面与模型工具调用同一份操作逻辑。模型先用 `catalog` 查具体 ID，再用 `draft` 或 `add`，避免猜风格名。

### huashu_printpress

| action | 作用 |
| --- | --- |
| `status` | 后台业务进程状态 |
| `capabilities` | 宿主提供方、实际有效来源与快速模型兜底状态 |
| `guide` | 原生工程的图层、坐标、字号、资源与字体契约 |
| `handoff` | 打开或导入已登记作品到编辑器 |
| `publish` | 导出 PNG + `.ppdesign` 并登记/回存作品 |
| `operations` / `call` | 分页发现并调用领域接口 |

模型写操作默认关闭，必须按用户授权显式传 `allowWrite: true`。`publish` 顶层字段为 `{ designId, revision, title, module, style, previewPath?, projectPath?, workId?, allowWrite: true }`；要求真图层时加 `requireLayers: true`。`call` 的领域参数才放入 `params`。

## 数据与安全

作品元数据保存在 `$DSH_HOME/huashu-design/library.json`，默认 `~/.dsh/huashu-design/library.json`。记录采用原子串行写入，损坏索引不会被静默覆盖。

内置源码编辑器完整读取与保存上限为 **128 KiB UTF-8**，超限明确拒绝、不截断；更大的工程通过「继续修改」处理。保存前把原文备份到源文件同目录，后缀 `.huashu.bak`；文件在外部变化时拒绝覆盖并保留编辑缓冲。编辑器只展示文本，不执行源码。

预览只读取已登记 HTML 及其同目录资源，生成有界内联副本，原文件不改写。小卡禁止脚本，全屏使用无同源权限的隔离 iframe，通过只允许当前作品与已登记 HTML 本体的桥接读写；关联 JS 或独立模板源码时只能预览。外部图片、外链样式、外链脚本与 `base`/`refresh` 一律剔除并给出有界提示。

HTTP 接口接入 DSH Connection 认证，写请求要求同源 JSON。静态资源只允许上游目录内的图片，拒绝目录穿越、符号链接与祖先 junction；作品路由只返回登记的单个文件，不开放相邻目录。HTML/SVG 作为附件下载，不在同源页面运行。

## 安装与开发

需要 Node.js >= 22.19.0、DSH >= 0.2.1-rc.2 < 0.3.0。由 DSH 插件管理器安装此目录。

### 先取上游快照

仓库不包含 `upstream/`：它是上游 huashu-design 的完整克隆（含 200MB+ 历史与大量二进制样张），逐 fork 复制没有意义。首次使用时自行拉取固定版本：

```powershell
git clone https://github.com/alchaincyf/huashu-design.git upstream
git -C upstream checkout e8d1148a80d5a281d4247cffe320add3df017928
```

插件按 `upstream-manifest.json` 记录的哈希校验资源；版本不一致时风格样张与手册路径会失效。`upstream/` 是独立仓库，本仓库不跟踪其 `.git`。

### 构建

Host 直接加载 JavaScript；Client 作者源码在 `src/client.js`，批印坊面板源码在 `src/printpress/`，经 esbuild 打包到 `lib/client.js` 与 `dist/printpress/`。修改后先构建，`check` 会重算产物并拒绝过期文件，避免安装成功却仍显示旧界面。

批印坊源码树不随包分发。构建内嵌面板前必须显式指定它的位置，没有机器相关的默认值：

```powershell
$env:HUASHU_PRINTPRESS_ROOT = '<你的批印坊源码目录>'
pnpm install --ignore-scripts
npm run build
npm run check
```

未设置该变量时，构建会直接报错并说明原因，不会静默产出一个空面板。

`npm test` 覆盖适配器逻辑与 HTTP 面；其中依赖批印坊源码树与 Electron 的用例在缺少 `HUASHU_PRINTPRESS_ROOT` 时自动跳过。

Node 导出脚本依赖 `playwright`、`pdf-lib`、`pptxgenjs`，随插件声明。Python 脚本、浏览器与 FFmpeg 按对应模块准备；Windows 本机使用 `py -3`，不要假设 `python` 已配置。云端配音等需用户自己的服务与凭据。

## 已知限制

- 真实打印机出纸与浏览器逐项视觉点击需人工确认；自动验收使用隔离目录覆盖导入、编辑、导出、照片匹配、任务取消、写入冲突与 HTTP 认证同源校验。
- 平面图片编辑不承诺还原文字图层；只有带真实图层的 `.ppdesign` 可逐层编辑。
- 系统打印、PSD 解析与原生像素操作依赖本机 Electron 与领域模块；独立桌面程序自身的更新、重启与目录迁移不在面板内提供。
